**Автор страницы:** Кублик Ольга  
**Проект:** сайт для абитуриентов РГПУ им. А. И. Герцена.

Документация описывает будущий проект сайта для абитуриентов: цели, пользователей, требования, архитектуру, API, базу данных и UML-диаграммы.

## Назначение системы

Система предназначена для помощи абитуриентам при выборе образовательной программы. Пользователь может просматривать программы, сравнивать проходные баллы, бюджетные и платные места, форму обучения, стоимость и вступительные испытания.

## Основные артефакты

- план проекта;
- требования пользователей;
- архитектура системы;
- спецификация API;
- модель базы данных;
- UML-диаграммы и поясняющие приложения.

В текущем MVP используется React-приложение, `json-server` и файл `db.json`. Для базы данных отдельно подготовлена модель Microsoft SQL Server.
