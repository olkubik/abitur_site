## 1.1. Проектные цели и ограничения

Цель проекта — разработать сайт для абитуриентов РГПУ им. А. И. Герцена, который помогает выбрать образовательную программу и получить ключевую информацию о поступлении.

Ограничения проекта:

- учебный формат разработки;
- ограниченный набор программ в MVP;
- отсутствие полноценного backend в текущем прототипе;
- использование `json-server` для демонстрации API;
- необходимость соответствия требованиям курсовой работы.

Качественные характеристики:

- понятная навигация;
- корректное отображение на разных экранах;
- доступность информации о программах;
- быстрый поиск и фильтрация;
- аккуратная визуальная подача данных.

## 1.2. Границы проекта

В проект входят:

- главная страница для абитуриентов;
- страница выбора программы;
- карточка образовательной программы;
- админ-панель для управления программами;
- REST API для данных MVP;
- документация проекта;
- модель базы данных.

В проект не входят:

- полноценная интеграция с официальными системами университета;
- реальная авторизация через университетские учетные записи;
- прием заявлений и документов через сайт;
- онлайн-оплата обучения.

## 1.3. Декомпозиция работ

| Блок работ | Содержание |
| --- | --- |
| Аналитика | анализ предметной области, пользователей и требований |
| Дизайн | оформление главной страницы, карточек и фильтров |
| Frontend | React-компоненты, маршрутизация, адаптивность |
| Данные | `db.json`, SQL-модель, справочники |
| API | описание ручек, OpenAPI, тестовые запросы |
| Документация | Docusaurus, Word-файлы, UML-диаграммы |
| Проверка | линтер, сборка, ручная проверка страниц |

## 1.4. График работ

| Этап | Срок | Результат |

| Анализ | 1 неделя | требования и предметная область |

## 1.5. Критерии достижения результатов

Проект считается выполненным, если:

- сайт открывается локально;
- основные страницы отображаются без критических ошибок;
- программы загружаются из данных;
- фильтры и сортировка работают;
- админ-панель позволяет менять программы;
- API описан и проверяется через `fetch`;
- документация собрана в Docusaurus.

## 1.7. Инфраструктура и службы

Для реализации проекта используются:

- Node.js и npm;
- React и Vite;
- Docusaurus;
- json-server;
- Microsoft SQL Server Management Studio;
- GitHub;
- VDS Ubuntu для будущего размещения;
- браузерные DevTools для проверки API.

## Корректировка планов

При выявлении несоответствий планы корректируются. Например, если отсутствует backend, API описывается как MVP на `json-server`, а полноценная серверная часть фиксируется как развитие проекта.
