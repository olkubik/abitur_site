# SQL Server для курсовой

Эта папка нужна, если база данных создается через SQL Server Management Studio.

- `schema.sql` - создание таблиц, связей, ограничений и индексов.
- `seed.sql` - заполнение базы тестовыми данными.
- `queries.sql` - примеры запросов для поиска и фильтрации программ.

## Как создать базу в SSMS

1. Открой SQL Server Management Studio.
2. Подключись к серверу.
3. Нажми правой кнопкой на `Databases`.
4. Выбери `New Database...`.
5. Назови базу `HerzenAdmission`.
6. Нажми `OK`.
7. Открой `New Query`.
8. В выпадающем списке баз выбери `HerzenAdmission`.
9. Выполни `schema.sql`.
10. Выполни `seed.sql`.
11. Для проверки выполни:

```sql
SELECT * FROM programs;
```

Если вывелось 8 программ, база создана правильно.

## Почему выбран SQL Server

Для проекта выбрана СУБД Microsoft SQL Server, так как она является надежной реляционной системой управления базами данных, поддерживает внешние ключи, ограничения целостности, индексы и язык SQL. Эти возможности подходят для хранения структурированных данных приемной кампании: образовательных программ, институтов, экзаменов и мероприятий.

Дополнительным преимуществом является наличие SQL Server Management Studio, которое позволяет удобно создавать таблицы, выполнять запросы и просматривать данные без разработки отдельной серверной панели. Для учебного проекта это упрощает администрирование базы и позволяет сосредоточиться на проектировании структуры данных и интерфейса сайта.

React-приложение не подключается к SQL Server напрямую, потому что данные для подключения к базе нельзя хранить в браузере. В рамках курсовой база данных спроектирована и заполнена отдельно, а подключение сайта к ней может быть реализовано в дальнейшем через серверную часть и REST API.
