# Сайт для абитуриентов РГПУ им. А. И. Герцена

React-приложение для курсовой работы: главная страница для абитуриентов, подбор образовательных программ, страница программы и простая админ-панель для управления данными.

## Технологии

- React
- Vite
- Leaflet для интерактивной карты
- JSON Server как демонстрационный REST API
- `db.json` как источник данных для MVP

## Локальный запуск

Установить зависимости:

```bash
npm install
```

Запустить сайт и API одновременно:

```bash
npm run start
```

Открыть сайт:

```text
http://localhost:5173
```

API локально работает по адресу:

```text
http://localhost:3001
```

## Основные команды

```bash
npm run dev
npm run api
npm run start
npm run build
npm run lint
```

## Данные

Основные данные для сайта и админ-панели находятся в файле:

```text
db.json
```

SQL-скрипты для описания структуры базы данных находятся в папке:

```text
sqlserver
```

## Деплой

Инструкция для VDS Ubuntu находится в файле:

```text
DEPLOY_UBUNTU.md
```

Для продакшена React-приложение собирается в `dist`, а API запускается на сервере через `pm2` и проксируется Nginx по пути `/api`.
